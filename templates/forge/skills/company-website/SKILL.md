# Company website workflow

Always read the repository `AGENTS.md` before acting. Use the existing file and terminal tools; do not create an Agent runtime or content platform.

For a first build, read `references/first-build.md`. For scoped user changes, read `references/modify-site.md`. For SEO changes, read `references/seo-baseline.md`.

After meaningful changes run `npm run verify`. Before delivery run `npm run verify:delivery` and visually inspect mobile and desktop layouts when browser tooling is available.
